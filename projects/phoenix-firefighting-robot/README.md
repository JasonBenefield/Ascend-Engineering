# PHOENIX — Firefighting Robot

**An ASCEND Engineering Project**

**Category:** Robotics | Mechatronics | Embedded Systems | Automation

**Project Status:** Development

---

## Project Overview

PHOENIX is a firefighting robotics project focused on developing a robotic platform capable of detecting and responding to fire-related hazards.

The project provides an opportunity to apply engineering principles in robotics, electronics, sensor integration, control systems, mechanical design, and system testing.

## Project Objectives

- Develop a robotic platform for firefighting applications.
- Investigate sensors and methods for detecting fire-related hazards.
- Design and integrate mechanical, electrical, and control subsystems.
- Develop and test robotic movement and response capabilities.
- Document engineering decisions, development progress, and test results.

## Engineering Development

This portfolio will document PHOENIX through the following stages:

1. Concept development and requirements
2. System architecture and component selection
3. Mechanical and electrical design
4. Software and control system development
5. Integration and prototyping
6. Testing, evaluation, and refinement

## Project Documentation

Detailed engineering documentation, photographs, diagrams, and software will be added as development progresses.
